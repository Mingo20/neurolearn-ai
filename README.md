## El problema

Aprender IA es abrumador sin una ruta clara.

## Qué hace

- Ruta de aprendizaje por niveles
- Progreso, niveles y logros
- Laboratorio de IA
- Lecciones generadas por IA

## Cómo está construido

**Tipo:** PWA

Aplicación de una sola página con lecciones generadas por un modelo.

**Tecnologías**

- HTML, CSS y JavaScript en un archivo
- Service Worker y manifest

**Backend**

- Ninguno propio

**Datos**

- Progreso local

## Datos sensibles

Progreso del estudiante.
